# 💬 TalkBridge

TalkBridge is a simple real-time chat application where users can create channels, send messages, and collaborate with teammates.

---

## 🚀 Features

* 🔐 User authentication (Signup/Login using Supabase)
* 💬 Real-time messaging
* 📢 Create and join channels
* 👥 Add teammates to channels
* 😊 Message reactions (emoji support)

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS (Tailwind), JavaScript
* **Backend:** Supabase (PostgreSQL + Auth + Realtime)
